# 隐私与分享策略

## 新增实时事件与阶段报告（2.0）

watch.py保存的JSONL以及report_events.py生成的JSON/Markdown只有私有模式，可能包含原始日志、IP、查询串、精确时间、本地来源/配置路径；没有--redact-share接口，不能调用旧privacy模块假装已经脱敏。报告中的代码块只解决展示边界，不解决公开隐私。基线结果也可能记录解释器路径及子进程命令，未经复核不公开。

## 批量报告私有版与分享版（仅analyze.py）

默认完整报告保留原始日志、IP、URL、错误文本、精确时间和本地文件路径，适合授权范围内排查，不适合直接公开。

--redact-share 在检测完成后创建新对象，不修改原日志或私有报告，按允许字段重建，不在原对象上简单替换关键词。

分享版：

- IP 替换为 IP-001 等代号，请求路径及配置路径名单替换为 PATH-001 等代号。
- 移除本地源文件与配置文件路径、查询串、原始日志、头部、精确时间、未知字段。
- 保留统计数量、状态码、规则类型、窗口阈值、原始行号和路径/IP 的相对关系。
- 不输出代号映射表；代号只在单次报告内一致，不用于跨报告关联。
- 未认识的新规则拒绝分享导出，防止未来字段被误带入。

## 不承诺匿名

时间模式、请求数量、关系和行号仍可能与外部材料关联；这是减少暴露的分享视图，不是匿名化证明，也不是所有类型秘密的通用识别器。输出目录、终端提示和调用命令本身也可能包含本地路径，不应直接截图公开。

分享报告不能代替完整原始证据。应将原始日志、私有报告保存在受控目录；对外仅选择已复核的 share.json 或 share.md。

## 发布包策略

build_release.py 仅收集明确列出的源码、合成样例、规则、测试和当前手册。不递归打包整个工作区，不包含 experiments、docs 历史报告、缓存、虚拟环境、环境变量或 .env。

合成样例允许修改，因此发布前仍应确认样例里没有自己填入的真实数据。规则文件是业务信息的一部分，若自行填写内部路径，请先改为公开演示配置。发布工具的白名单不能判断使用者写入白名单文件的新秘密。

## 测试与边界

回归测试使用假密钥哨兵，检查原始证据、参数、来源 IP、私有路径不会进入分享 JSON/Markdown；验证原始对象不变，且行为证据只保留行号。Markdown 使用缩进代码块处理日志内容，另做过 HTML 标签与反引号的受控渲染检查。

未进行全面安全审计或生产合规认证，不宣称可处理任意敏感数据或任意第三方 Markdown 渲染器。
